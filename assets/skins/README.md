# 여운 - 세 가지 공간과 안내자

| 공간 | 캐릭터 | 전체 테마 |
|---|---|---|
| 카페 | 장식 없는 셔츠, 자연스럽게 모은 손 | 세이지, 창, 컵, 나무 바닥 |
| 마음 진료실 | 아이보리 가운, 단정한 짧은 옆가르마 | 차분한 청록, 창, 작은 식물 |
| 놀이방 | 크림색 고양이, 장식 없음 | 살구색 프레임, 매트, 쿠션, 공, 발자국 |

캐릭터만 바꾸지 않고 앱 바깥 배경, 프레임, 상단, 하단 탭, 공통 버튼과 패널까지 함께 바뀐다. 테마는 `themes.json`, 방 배경은 `RoomWallpaper.tsx`에서 관리한다. `wallpaper.svg`는 실제 웹 렌더에서 내보낸 동일 배경이다.

- 몸 포즈 PNG 9개: 기본 / 인사 / 설명. PNG는 원본을 보존한 불투명 마스터다.
- SVG 클리핑 9개: 원본 PNG의 배경을 런타임에 가려 방 배경에 합성한다. 원본 PNG를 투명 파일로 표기하지 않는다.
- 얼굴 SVG 42개: 세 캐릭터 × 7표정 × 눈 뜸/깜박임. 사람 얼굴과 의사 머리는 코드로 그린다.
- 방 배경 3개, 전체 벽지 3개. 사람의 팔과 손, 고양이 몸은 생성 이미지이며 얼굴과 꼬리는 SVG 레이어다.
- 표정: 편안함, 반가움, 경청, 응원, 기쁨, 걱정, 진지함. 지침·분노·비난 표정은 포함하지 않는다.
- 움직임: 220ms 포즈 전환, 작은 숨쉬기, 150ms 눈 깜박임. 비활성/백그라운드와 움직임 줄이기에서 반복 자원을 중단한다.
- 공간 선택은 기기의 공개 외형 설정 하나만 저장한다. 상담 내용, AI 프롬프트, 계정 소유권은 변경하지 않는다.

생성 도구와 프롬프트는 `production-prompts.json`, 각 PNG 해시는 `catalog.json`에 있다. 균일 배경/팔 형태를 검토하고 투명 출력의 내부 구멍이 있던 시안은 제외했다. 원본에는 약한 명암이 남아 있어 정확히 몇 RGB 색만 쓰는 파일은 아니다.

야옹 소리는 [freemaster2의 CC0 녹음](https://commons.wikimedia.org/wiki/File:Meow_of_a_Siamese_cat_-_freemaster2.wav)을 짧고 조용하게 가공했다. 출처와 해시는 `../audio/cat_meow.license.json`. 기존 효과음 설정이 켜져 있고 사용자가 공간/캐릭터를 직접 누를 때만 재생하며, 녹음 중/백그라운드에는 중단한다.

의사는 가상의 AI 안내 캐릭터이며 실제 의료진의 진료를 제공한다는 의미가 아니다.
