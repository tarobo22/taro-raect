# 0.2 선택 다이얼 연결

근거는 `output/yeoun-specification-20261105/docs/04-screen-specs.md` 19·20·26·30행 및 S05 139~151행, `output/yeoun-button-sounds-20261105/docs/FLOW-REVIEW.md` 29~30·39~45·75·80행이다. 기획 0.2의 기존 값 탐색과 명시 확정을 연결한다.

- `SelectionDial`의 기본은 -135°~135°의 270° 범위다. 하단의 빈 구간을 넘어 계속 돌려도 양 끝값 사이로 건너뛰지 않는다. 끝값의 이전/다음은 비활성화하고 같은 값에는 tick을 다시 보내지 않는다. 이전/다음은 48dp이며 현재 이름·순번·범위를 표시/낭독한다. 웹 방향키와 Home/End, 네이티브 접근성 increment/decrement를 제공한다.
- 알림 시간의 두 다이얼은 `circular`를 명시하여 기존 시계의 23→00시, 59→00분 순환을 유지한다. 호흡 타이머와 알림 예약 계약은 바꾸지 않는다.
- `CardSlotDial`은 서버가 준 12개 슬롯의 ID/번호만 사용한다. 회전·키보드·이전/다음은 초점만 옮긴다. 별도 **이 슬롯 선택/선택 해제**가 기존 선택 함수를 호출한다. 최대3장, 선택 순서, 선택 초안과 `expected_version`/`slot_ids` 확정 요청은 기존 계약을 사용한다. 12개 카드 그리드와 전체 확정 CTA도 그대로 제공한다.
- `MoodDial`의 탐색값은 기록 초안과 분리한다. **탐색한 마음 확인**으로 시트를 열고 **이 마음으로 선택**을 누를 때만 기존 mood 값을 초안에 반영한다. 취소·뒤로가기는 mood/본문을 변경하지 않는다. 기존 마음 칩은 직접 선택할 수 있고 실제 저장 CTA는 별도다. 시트는 움직임 줄이기 설정을 따른다.
- 다이얼은 손을 대는 즉시 responder를 가져가지 않는다. 수평 이동으로 회전 의도를 확인하고, 세로 이동은 부모 스크롤에 맡긴다. 종료·취소·unmount에서 제스처 상태와 늦은 측정 콜백을 무효화한다. 회전 끝에도 카드 선택이나 기록 저장을 실행하지 않는다.

새 단위2개는 각 눈금·270° 양 끝·빈 구간을 넘는 연속 이동·키보드 경계·시계 순환을 확인한다. 새 브라우저1개는 Home/End, 탐색만으로 선택/요청하지 않음, CDP 세로 터치 스크롤, 다이얼 CTA와 기존 그리드의 혼합 선택 및 정확한 서버 payload, 마음 시트의 취소/확인·기존 칩·본문 보존·48dp를 함께 검증한다. 이 묶음은 새 기능 테스트와 양쪽 타입 검사만 실행하며 전체 회귀와 Android 실기기 조작은 최종 통합 단계에서 확인한다.
