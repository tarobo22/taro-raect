# 타로 0.2 선택·셔플·공개 모션

기존 서버 슬롯과 선택 흐름에 D03/D09/D10 연출만 추가한다. 모션 컴포넌트는 카드 ID, 선택 순서, 체크, 재화나 API 명령을 소유하지 않는다. 그리드/다이얼/확정 버튼의 접근성과 기존 선택 개수·opacity를 유지한다.

| 항목 | 설계값 | 상태 경계 |
| --- | --- | --- |
| D03 세 장 공개 | 준비된 이미지마다 420ms 회전, 위치별 지연 0/220/440ms | 같은 준비 시점이면 마지막 공개까지 860ms. 기존 이미지 준비와 공개 ledger를 사용한다. 네트워크/디코딩 시간을 포함한 완료 시간 보장은 아니다. |
| D09 선택·해제 | translateY 0 ↔ -4, 180ms | 기존 선택 상태를 장식한다. 빠른 반대 선택은 현재 위치에서 새 목표로 이동한다. 체크와 선택 순서는 즉시 기존 상태에 맞춘다. |
| D10 다시 섞기 | opacity .55 → 1, 180ms | DrawV2가 서버 성공 응답의 새 version을 반영할 때만 시작한다. 첫 mount·같은 version 재렌더·실패는 연출을 시작하지 않는다. |

`TarotSelectionMotion`/`TarotShuffleMotion`은 ActivityEffect로 전경 수명을 관리한다. 백그라운드·unmount 때 실행 중인 animation을 멈추고 최신 선택 위치/opacity 1에 정착한다. 전경으로 돌아올 때 이전 연출을 재생하지 않는다. 움직임 줄이기는 즉시 정적인 최종 상태를 사용한다. 지연된 데이터 변경이 백그라운드에서 발생해도 전경 복귀를 기다리는 animation을 만들지 않는다.

셔플 실패는 기존 카드 선택과 서버 슬롯을 유지한다. 성공 후 선택 초기화·새 슬롯·버전 반영은 기존 DrawV2 함수가 수행한다. ReadingV2는 공개 지연값 130→220ms만 변경하며 AI 요청 함수, CardReveal의 회전·이미지 처리·중복 방지 코드는 변경하지 않는다. 글로벌 UI/Talk/Character/route opacity 및 Home 스타일은 변경하지 않는다.

새 브라우저1개는 실제 RAF 중간 이동 프레임, 선택/해제, 실패한 셔플의 불변 상태, 성공한 새 버전의 fade, reduced 설정 왕복과 선택 초안 유지, reduced의 정적 위치·투명도, 세 장 공개 시작 간격과 정확한 서버 슬롯 ID를 검증한다. 기존 dials/card-reveal 브라우저2개와 관련 단위5개, RN/Web 타입 검사·Web build만 실행한다. 실기기 촉감·프레임률과 전체 통합 회귀는 별도 최종 검증이다.
