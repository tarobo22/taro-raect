# 남은 결정안 - 구현 승인으로 간주하지 않음

이번 확정 범위의 통계·달력·즐겨찾기·기록 AI 요약·Android 알림은 구현했다. 아래는 원본의 미정/후속 항목에 대한 구체적인 결정 초안이며, 공급자나 과금 규칙을 임의로 확정하지 않았다.

| 항목 | 제안하는 요구사항 | 결정할 내용 | 승인 후 TDD 단위 |
|---|---|---|---|
| P1-02 로그인·동기화 | 게스트 연속성을 보존하고 명시적 계정 전환. 검증된 토큰으로 동기화하며 연결 만료·복구·충돌을 안내 | 이메일/소셜 공급자, 게스트 병합/이전 정책, 같은 날 기록 충돌, 계정 삭제·복구 범위 | 인증 port 계약 → 게스트 이전 원자성/재시도 → 충돌·다른 기기 세션 → 로그인·복구 화면 |
| P1-03 운영 관리 | 사용자 API와 분리한 관리자 인증. 자산 권리·프롬프트 버전·사용량·피드백·OTA를 역할별 열람/변경 | 운영 계정 발급, 읽기/변경 역할, 자산 발행·프롬프트·OTA 승인 주체와 감사 로그 보존 | 권한 거부 → 변경 이력 → 버전 게시·되돌리기 → 운영 화면 |
| P2-01 결제·유료 덱 | 상품·권한을 서버 영수증과 연결. 구매·복원·취소·만료·환불 후 권한을 일관되게 반영 | 유료 상품·판매 국가·가격/구독, 플랫폼별 규칙, 게스트 구매 이전·환불 정책 | 위조/중복 영수증 → 상태 전이·이벤트 재전송 → 복원·만료 → 결제 화면 |
| P2-02 분기 스토리 | 콘텐츠 노드 ID·버전·대사·예/아니요 다음 노드·결말을 데이터로 정의. 선택 후 이어하기 보존 | 실제 시나리오·분기·결말, 편집 권한, 콘텐츠 업데이트 후 진행 중 이야기 처리 | 끊긴 링크·순환 검증 → 선택 중복/저장 충돌 → 이어하기 → 이야기 화면 |

공통 원칙: 승인된 데이터 모델·API·화면 명세를 갱신한 다음, 한 기능의 의미 있는 실패를 확인하고 구현·리팩터링·검증을 통과시켜 기능 단위로 커밋·push한다. 정책이나 제공자 계정이 미정이면 동작하는 것처럼 표시하지 않는다.

출시 전 결정: 외부 78장 덱 최종 그림체·권리·발행 승인, 한국어 GPT/전사 모델과 비용·지연 평가, 운영 호스팅·스토어 서명. API 응답 목표 및 실기기 FPS는 별도 측정 계획으로 다루며 이번 테스트 수로 대체하지 않는다.
